No Riichi No Fuku · Windows 11 x64 테스트판

기본 플레이는 무음으로 진행됩니다. 음악이나 이미지 팩을 등록하거나 이미지 생성 설정을 열지 않아도 엔딩까지 플레이할 수 있습니다.

처음 실행
1. 게임 ZIP을 빈 폴더에 전부 압축 해제합니다. EXE와 resources 폴더를 함께 둡니다.
2. No-Riichi-No-Fuku.exe를 실행합니다. 기본 대국에는 로그인, 인터넷, Python, Docker, ComfyUI 설치가 필요하지 않습니다.
3. 참가할 CPU를 3명 이상 골라 명단을 확정합니다. 이어서 이번 대국의 상대 3명을 선택하고 동풍전을 시작합니다.
4. 게임 창을 닫았다가 다시 실행하면 저장된 대국으로 돌아갑니다.

대국 진행과 엔딩
동풍전 최종 4위가 미완료 CPU이면 그 CPU의 단계가 하나 올라갑니다. 모든 참가 CPU가 3단계에 도달하면 마지막 결산을 확인한 뒤 엔딩이 열립니다.
엔딩에서 ‘오마케로 계속하기’를 누르면 완료한 참가자들과 새 대국을 시작할 수 있습니다.

저장 위치와 백업
탐색기 주소 표시줄에 %LOCALAPPDATA%\NoRiichiNoFuku 를 입력하면 현재 Windows 계정의 게임 데이터가 열립니다.
게임을 종료하고 프로세스가 끝난 뒤 이 폴더 전체를 백업합니다. 대국 DB, 설정과 게임이 보관하는 미디어를 함께 복사합니다.
외부에서 관리하는 팩 원본 및 ComfyUI 모델 파일은 해당 보관 위치에서 별도로 보관합니다.

새 테스트판으로 교체
게임 종료 → 데이터 폴더 전체 백업 → 새 ZIP을 별도 빈 폴더에 압축 해제 → 새 폴더의 EXE 실행 순서로 진행합니다.
같은 Windows 계정에서 기본 경로로 실행하면 기존 데이터를 읽습니다. 이름·참가 명단·진행 중인 대국을 확인하세요.
백업을 복구할 때는 게임을 종료하고 현재 데이터 폴더를 다른 이름으로 보관한 뒤 백업 폴더를 원래 위치로 복사합니다.
이전 빌드로 돌아갈 경우 그 빌드로 마지막에 백업했던 데이터와 함께 사용합니다.

이미지 생성
마작패 그림은 게임에 포함되어 있습니다. 캐릭터 이미지는 사용자 PC에서 생성합니다.
캐릭터 프롬프트·팩 설정 → 캐릭터 편집에서 CPU를 추가하거나 이름을 변경할 수 있습니다.
직접 이미지를 생성할 때만 로컬 ComfyUI를 실행하고 게임의 이미지 생성 설정에서 연결을 확인합니다.
이 테스트판의 소스 커밋은 함께 있는 BUILD-SOURCE.txt에서 확인할 수 있습니다.

캐릭터와 사운드 팩 주고받기
받은 packs 폴더를 게임 EXE 옆에 복사합니다. 캐릭터 프롬프트·팩 설정 → 팩 목록·진단 → 폴더 다시 검색을 누릅니다.
packs/characters/<팩 ID>/manifest.json과 images/에 캐릭터와 단계 이미지를 둡니다.
packs/voices/<캐릭터 ID>/<음성팩 ID>/, packs/bgm/<팩 ID>/, packs/sfx/<팩 ID>/에는 지정된 이름의 음원을 둡니다. 음악·효과음·음성은 manifest.json 없이도 게임 시작 시 인식합니다.
파일 확장자는 wav, ogg, mp3입니다. 같은 세트 안의 같은 이름은 한 확장자만 사용합니다.
BGM: title, selection, game, result, ending / 효과음: tile_discard, tile_shuffle, riichi_stick
음성: chi, pon, kan, riichi, ron, tsumo, win, match_first, match_last, defeat_stage_1, defeat_stage_2, defeat_stage_3
예: packs/bgm/default/game.ogg, packs/sfx/wood/tile_discard.wav. 없는 슬롯은 기본 세트에 있으면 그 파일을 사용합니다.
캐릭터 편집 → 이 캐릭터의 엔딩에서 프롬프트를 편집하거나 기본값으로 생성한 뒤 저장합니다. 마지막 완료 캐릭터의 엔딩 이미지가 표시됩니다.
캐릭터 편집에서 대상 CPU를 선택한 뒤 팩을 연결·적용합니다. 공용 음악·효과음 팩은 사운드 설정에서 선택합니다.
캐릭터 편집 → 배포용 캐릭터팩 내보내기에서 내보내면 exports 아래에 새 폴더가 생깁니다. 그 안의 packs 폴더를 통째로 압축해 전달하세요.
게임을 옮기거나 업데이트할 때 EXE 옆의 packs와 exports도 복사하세요. 세이브와 연결된 미디어의 백업 위치는 위의 저장 위치와 백업을 따릅니다.

ComfyUI 모델을 설정하면 화면에 필요한 빈 이미지를 순서대로 생성해 저장합니다. 대기 수는 화면 아래에 표시됩니다.
프롬프트 수정 후 기존 그림을 바꾸려면 이미지 재생성을 누릅니다. 편집 화면에서 수동으로 생성한 미리보기는 이 이미지 저장을 누릅니다.
저장한 단계·엔딩 그림의 사본은 게임 폴더 images/<캐릭터 ID>/에 있습니다. 다른 PC에 적용할 때는 내보낸 캐릭터팩을 사용하세요.
