No Riichi No Fuku · Windows x64 테스트판

처음 실행
1. 게임 ZIP을 빈 폴더에 전부 압축 해제합니다. EXE와 resources 폴더를 함께 둡니다.
2. No-Riichi-No-Fuku.exe를 실행합니다. 기본 대국에는 로그인, 인터넷, Python, Docker, ComfyUI 설치가 필요하지 않습니다.
3. 참가할 CPU를 3명 이상 골라 명단을 확정합니다. 이어서 이번 대국의 상대 3명을 선택하고 동풍전을 시작합니다.
4. 게임 창을 닫았다가 다시 실행하면 저장된 대국으로 돌아갑니다.

저장 위치와 백업
탐색기 주소 표시줄에 %LOCALAPPDATA%\NoRiichiNoFuku 를 입력하면 현재 Windows 계정의 게임 데이터가 열립니다.
게임을 종료하고 프로세스가 끝난 뒤 이 폴더 전체를 백업합니다. 대국 DB, 설정과 게임이 보관하는 미디어를 함께 복사합니다.
외부에서 관리하는 팩 원본 및 ComfyUI 모델 파일은 해당 보관 위치에서 별도로 보관합니다.

새 테스트판으로 교체
게임 종료 → 데이터 폴더 전체 백업 → 새 ZIP을 별도 빈 폴더에 압축 해제 → 새 폴더의 EXE 실행 순서로 진행합니다.
같은 Windows 계정에서 기본 경로로 실행하면 기존 데이터를 읽습니다. 이름·참가 명단·진행 중인 대국을 확인하세요.
백업을 복구할 때는 게임을 종료하고 현재 데이터 폴더를 다른 이름으로 보관한 뒤 백업 폴더를 원래 위치로 복사합니다.
이전 빌드로 돌아갈 경우 그 빌드로 마지막에 백업했던 데이터와 함께 사용합니다.

이미지 생성
직접 이미지를 생성할 때만 로컬 ComfyUI를 실행하고 게임의 이미지 생성 설정에서 연결을 확인합니다.
이 테스트판의 소스 커밋은 함께 있는 BUILD-SOURCE.txt에서 확인할 수 있습니다.
