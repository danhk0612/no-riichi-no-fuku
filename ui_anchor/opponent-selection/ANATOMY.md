# 동풍전 상대 선택

## 관찰 범위

Windows Electron 창에서 React·TypeScript가 선택 화면을 그린다. 참가 명단 확정 후 서로 다른 CPU 세 명을 골라 동풍전을 시작한다. 선택 순서는 좌석 순서다. 명단을 처음 정하는 화면은 최소 세 명을 받는 별도 단계다. 화면은 마우스 호버와 클릭, Tab·Shift+Tab 포커스, 기본 버튼의 Enter·Space 활성화를 사용한다. 진행 초기화는 별도 확인 절차를 거친다. 오마케 또는 미완료 CPU가 세 명 미만인 경우 완료 CPU 선택이 가능하다.

## 제공된 여섯 화면

| 화면 | 직접 관찰한 정보 순서와 조작 |
| --- | --- |
| 첫 장면 | 전면 캐릭터와 탁자가 화면 대부분을 차지한다. 제목은 좌상단, 시작은 하단 중앙, 종료는 우하단에 있다. |
| 메인 | 좌측 약 40%에 세 가지 행동을 세로 배치하고 선택한 행동만 색면으로 강조한다. 우측에는 인물과 장소가 이어진다. |
| 상대 선택 | 좌상 제목에서 우상 인원수로 읽고, 큰 인물과 설명을 본 후 아래 얼굴 목록에서 선택한다. 마지막 행에서 좌석과 시작을 함께 확인한다. |
| 대국 | 녹색 탁자 중앙에 국·남은 패, 둘레에 각 좌석, 하단에 내 손패와 현재 가능한 행동이 있다. 손패 위로 들린 패가 현재 조작 대상을 나타낸다. |
| 설정 | 화면·소리 두 열에서 항목과 값이 같은 행에 놓인다. 초점은 테두리로, 적용·복귀는 하단의 서로 다른 버튼으로 표시한다. |
| 결과 | 좌측 약 35% 인물, 우측 큰 내 순위와 점수, 아래 네 자리 표 순서다. 강조 행과 후속 행동의 위치가 구분된다. |

## 대표 기준과 적용

사용자가 제공한 ‘대국 상대 3명 선택-3.png’, 1672×941. 아래 수치는 이미지상의 근사치다. 상단 지시 띠 0–8%, 인물·정보 9–53%, 후보 55–84%, 좌석·시작 86–99%. 큰 그림은 폭 53%, 프로필 설명은 41% 정도다. 카드 여섯 장이 한 줄을 이룬다. 약 80px의 인물명, 30px 전후의 항목, 24px 안팎의 카드 이름이 위계를 만든다. 1–2px 구획선, 직각 모서리와 좁은 간격을 쓴다. 붉은 면은 제목, 체크 모서리, 시작 버튼에 집중된다. 보고 있는 인물은 이중 외곽선, 참가자 세 명은 각각 체크, 좌석 순서는 하단 번호로 읽는다.

이 게임에서는 상단에 동풍전과 선택 수, 가운데에는 단계 CG와 현재 캐릭터의 성향·의상 단계·난이도, 아래에는 얼굴 행과 좌석순 명단을 둔다. 숫자 나이가 없는 데이터에는 나이를 만들지 않는다. 전신과 이미지 편집, 진행 초기화, 이름 편집은 기존 기능으로 유지한다. 방향키·Esc 전용 이동과 뒤로 버튼은 이 화면의 입력 계약에 없다.

| 역할 | 이 화면의 표현 |
| --- | --- |
| 바탕 | 탁자 옆 점수 기록지의 미색 #f4f0e5 |
| 글자 | 먹색 #182e29, 본문은 맑은 고딕 계열 |
| 자리와 선택 | 탁자 펠트의 녹색 #184b40, 체크와 좌석 번호를 병기 |
| 주목 | 황동 #cda760, 키보드 초점과 동풍 표식 |
| 구획 | 연한 회녹 #c6c7b7, 얇은 실선 |
| 이름 | 명조 계열의 큰 한글 이름, 점수판처럼 폭이 일정한 좌석 숫자 |

```
게임 제목 · 기존 설정
동풍전 / 상대 선택                                   선택 수
단계 그림                          이름 · 성향 · 단계 · 난이도
후보 얼굴과 이름 × 참가 명단
좌석 1             좌석 2             좌석 3         동풍전 시작
```

이 화면의 가장 큰 활자는 현재 보고 있는 상대의 이름이다. 이미지가 없는 설치에서도 이름·성향·좌석을 읽을 수 있어야 한다.

## Windows 실행 캡처와 비교

| 실행본 비교 | 큰 차이 세 가지와 반영 내용 |
| --- | --- |
| 첫 캡처 | 좌우 여백을 줄여 후보 행을 넓혔다. 얼굴 영역을 창 높이의 13%에서 20%로 높였다. 아래 명단에 ‘좌석 순서’와 번호 표식을 붙였다. |
| 두 번째 캡처 | 큰 그림의 윗부분이 잘려 위쪽을 기준으로 맞췄다. 선택 인원을 독립된 녹색 면으로 강조했다. 화면 제목 옆에 필요한 인원수를 안내했다. |
| 세 번째 캡처 | 인물 정보표의 항목과 값을 키웠다. 후보와 하단 좌석의 이름을 키웠다. 1100×720 창에서 시작 버튼이 접혀 보인 문제는 낮은 창 전용 간격과 사진 높이로 고쳤다. 최종 버튼 하단은 592px였다. |

기준에는 없는 게임 설정과 플레이어 이름이 실제 화면 위쪽에 있다. 1672×941의 최종 화면에서 큰 그림과 정보는 대략 y=207–563, 후보는 y=580–817, 좌석과 시작은 y=837–906에 놓인다. 창이 작거나 사용자가 전신·단계 안내를 펼치면 세로 스크롤을 사용할 수 있다.

격리된 Windows 11 x64 EXE에서 빈 데이터의 이미지 0장, 테스트용 로컬 생성 결과 8장을 각각 확인했다. 마우스 호버·클릭, Tab과 Shift+Tab, Enter와 Space, 세 명 미만의 시작 제한, 세 명 선택 후 추가 선택 제한, 해제·교체와 실제 대국 좌석 순서를 확인했다. 캡처는 별도 로컬 폴더의 round-01.png, round-02.png, round-03.png, final.png, compact.png, empty.png, comparison.png에 보관했다. 완료 CPU만 남은 진행 상태와 보조공학 낭독은 이 실행에서 검증하지 않았다.

적용한 스킬은 [game-ux-ui-design](https://github.com/SillyToolValley/game-ux-ui-skill/tree/b13b9cb70b1b5a906c0eec6cd7054e2df4a1337b)이다. 공통 디자인 규칙은 화면 방향 승인 후 정리한다.

## 파란색과 다인원 명단 반영

선택 강조는 남색 #284a70, 바탕은 옅은 회백색 #f1f2ef, 게임 외곽은 어두운 파랑 #121e30을 사용한다. 게임 헤더에는 설정 버튼 하나를 두고 이름·난이도·사운드·캐릭터·이미지 생성 항목은 설정 안에서 연다.

후보 행은 Windows 창에서 다섯 칸, 너비 720px 이하에서는 세 칸이다. 행 아래의 이전·다음으로 후보를 바꾸며 선택한 사람은 그대로 유지한다. 오른쪽에는 이름과 성향·의상 요약을 두고, 설명·신체 정보와 전신 이미지는 각각 별도 레이어에서 확인한다. 1000×720 Windows 창에서 여섯 번째 후보를 선택한 뒤 첫 페이지로 돌아와 명단 확정과 동풍전 시작을 확인했다.
