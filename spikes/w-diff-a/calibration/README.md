run은8worker·대국당5,000step·split별wall2,700초 한도를 적용한다. 실제 총 실행시간도 사전45분
예산과 대조한다. 실패/seed 제외/후보 검색으로 성공 표본만 남기지 않는다.
최종 검토에서 순서대로 결과를 기다리는 동안 deadline 검사가 멈추고 executor 종료가 남은
작업을 기다리는 문제를 수정했다. 이제 남은 시간만큼 기다리며 시간 초과/worker 오류에는
실행 중·대기 중 작업을 모두 종료한다. 제한 초과 시 새 결과 파일을 쓰지 않는다.
`test_budget.py`는 결과 순서, 첫 작업 지연과 대기 작업 취소, worker 오류 후 종료를 검사한다.
`finalize.py`는 최종 분석 도구로 전체 격자/중복/누락, v1 원본 통계·script hash,
독립 프로세스 check 자료(시간 제외), holdout12개 추출 전체대국 trace를 대조한다.
`evidence/sources.json`은 최종 도구/계획·JSON 근거의 SHA256이다.

## 해석 범위

인접 점수차는 높은-낮은 레벨, 순위차는 음수가 개선이다. 각seed의4좌석 평균을 먼저 구한다.
설명용95% 구간은 df31 t근사 계수2.04이며, 인접27비교×점수/순위 총54개 가족에 대한
Bonferroni **정규근사** 구간도 함께 저장한다. 후자는 정확한 동시 t구간이 아니다.
비인접 비교의 같은 폭 구간은 탐색용이며 추가 비교까지 가족오류를 보장하지 않는다.
연속 고정seed의 독립성/정규성·마작 전체 모집단의 무작위 추출을 가정할 수 없다.

연구용 실용 차이 권고는 인접 평균 +500점 이상, 평균순위 -0.05 이하, 보정구간의 개선 방향이다.
이는 제품 완료 기준의 사용자 승인이 아니다. 세 조합에서 모든 인접 구간을 만족해야
10개 강도 채택 검토를 권고한다. 표본 평균이 우연히 올라가는 것만으로 채택하지 않는다.
각성향의 장기 표본은5~6seed뿐이므로 캐릭터별 강도 보장으로 일반화하지 않는다.

공통 입력의 최소 샹텐 초과량은 과도한 패효율 실수의 진단 지표다. 안전한 fold도 초과할 수
있어 정답/실전 강도를 대신하지 않는다. 같은 corpus의 v1/v2 비교만 사용한다.
성향값 불변과 행동상 성향 표현은 별도 지표다. 비discard/fold의 원 판단 일치와 성향 간
행동 차이를 확인하지만, 인간이 체감하는 캐릭터 특성 비율까지 보장하지 않는다.

격리 저장 복구는 기존 session에 agent factory를 주입하는 기술 검증이다.
현재 설정을 실제 인수로 전달해 복구는 저장 profile 우선, 새 대국은 변경 설정을 사용한다.
production policy3 decoder/파일 DB/설정 API·UI는 미구현이며 제품 저장 호환 완료가 아니다.
Windows/build/browser/개인 PC/인간 상대 검증은 이번 문서·spike 범위에서 수행하지 않았다.
W04/W05의 제품 path filter 대상도 아니다. 기존 Windows 결과를 이번 head의 검증으로 쓰지 않는다.

## 성향·재현·전체 복구와 비용

새 seed701 실제 공개관측160개 × 기존6성향+극단2종 ×10레벨=12,800입력에서 두 독립 agent의
