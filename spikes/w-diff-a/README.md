# W-DIFF-A — 격리 난이도 후보 검증

**결론:** 기존 Tier2 판단 + 독립적인 합법 버림패 실수율로 10개의 행동 설정을 만들 수 있다.
낮은/높은 후보의 실전 차이는 관측했지만 **10개의 인접 강도 구간이 모두 구별된다는 검증은 실패**했다.
이 후보 표를 제품 기본값으로 채택하지 않는다. 기존 Tier0/1/2 대조군끼리도 이번 표본에서
강도 순서를 입증하지 못했다. L10은 기존 Tier2(policy2)와 동일하며 더 강한 AI가 아니다.

기준: main `8fb9b80a471090b43ac648597051e788c0767186`, PR #83/#84 병합 후.
시작 때 열린 별도 PR은 Docker 문서 #35. 기존 다른 worktree 변경은 건드리지 않고
`task/w-diff-a-difficulty-spike`에서 작업했다. 제품/backend/frontend/migration/legacy fixture 변경 없음.
규칙/진행/CG/정산/오디오/콘텐츠는 기존 경로를 사용한다.

## 재현

새 의존성은 없다. 출력은 저장소 밖 임시 경로를 지정한다.

`profiles.py`: profile 후보,`compare.py`: 대국/시간,`verify.py`: 공통 입력/격리 replay,

변경하지 않았다. 기존 Tier agents와 검증 adapter/session을 재사용하는 spike runner만 만들었다.
`evidence/`는 합성 검증 통계·hash다. 사용자 DB/CG/오디오/전체 관측 자료는 포함하지 않는다.
`matches.json`의 대국별 seed/좌석/결과/trace와 `sources.json`의 스크립트 SHA256으로 대조한다.
시간 수치는 호스트 부하에 따라 달라지고 결과/행동 hash는 같은 환경·입력에서 같아야 한다.

## 후보와 측정 조건

L=1..10, 실수율 p=(10-L)/10. 모든 레벨은 Tier2(policy2)의 원래 성향 6값과 RNG를 유지한다.
